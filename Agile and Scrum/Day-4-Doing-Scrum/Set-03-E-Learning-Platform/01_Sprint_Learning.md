# Day 4 – Set 3: E-Learning Platform – Sprint Planning

## 1. Project Overview

This assignment focuses on sprint planning and scope management for an e-learning platform. The development team is working in a 10-day sprint with an expected velocity of 30 story points.

The scenario involves planning sprint work and handling a new certificate-download feature requested by the Product Owner on Day 6.

## 2. Objectives

- Plan a sprint using the given velocity of 30 story points.
- Define a measurable Sprint Goal.
- Analyse the impact of new requirements during a sprint.
- Identify and resolve development impediments.
- Calculate sprint velocity.
- Conduct a Sprint Retrospective.
- Understand how automation supports the Definition of Done.

## 3. Assignment Tasks

| Task | Description |
|---|---|
| Task 1 | Sprint planning using a supplied backlog and velocity of 30 points |
| Task 2 | Analyse the impact of the certificate-download request |
| Task 3 | Prepare a blocked developer's stand-up update and Scrum Master's follow-up |
| Task 4 | Calculate sprint velocity and explain partially completed work |
| Task 5 | Conduct a Start-Stop-Continue retrospective and prepare three SMART actions |
| Task 6 | Explain how unit tests, linting and automated pipelines support the Definition of Done |
