# Task 6 – JIRA Backlog, Definition of Ready and Definition of Done

## 1. Introduction

JIRA is an Agile project management tool used to create and manage product backlogs, user stories, tasks and sprints. It helps the Scrum team track work throughout the development process.

## 2. JIRA Project Setup

**Project Name:** Doctor Appointment System

**Project Type:** Scrum

**Project Goal:** Develop a mobile application that allows patients to book, reschedule and cancel doctor appointments and receive appointment reminders.

## 3. Definition of Ready (DoR)

Definition of Ready describes the conditions that a user story must satisfy before the development team starts working on it.

### DoR Checklist

- [ ] The user story is clearly written.
- [ ] The user story has a defined business value.
- [ ] Acceptance criteria are documented.
- [ ] The story is small enough to be completed within a sprint.
- [ ] Dependencies and required information are identified.
- [ ] The story has been estimated by the team.
- [ ] The story has been prioritised by the Product Owner.

## 4. Definition of Done (DoD)

Definition of Done describes the conditions that must be satisfied before a user story is considered completed.

### DoD Checklist

- [ ] All planned development work is completed.
- [ ] The code follows the team's coding standards.
- [ ] Unit testing is completed successfully.
- [ ] Integration testing is completed where required.
- [ ] Acceptance criteria are satisfied.
- [ ] Code review is completed.
- [ ] No critical or high-priority defects remain.
- [ ] Relevant documentation is updated.
- [ ] The completed functionality is demonstrated to the Product Owner.
- [ ] The user story is moved to the Done status in JIRA.

## 5. JIRA Workflow

The team follows this workflow to track the progress of each user story:

1. **To Do:** The story is ready for development but work has not started.
2. **In Progress:** A developer is actively working on the story.
3. **In Review:** The completed work is being reviewed and tested.
4. **Done:** The story satisfies the Definition of Done.

## 6. Conclusion

The JIRA product backlog organises the four epics and twelve user stories for the Doctor Appointment System. The Definition of Ready ensures that stories are prepared before development begins, while the Definition of Done ensures that completed work meets the team's quality standards.
