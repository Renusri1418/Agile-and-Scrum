## 2. Definition of Done (DoD)

The Definition of Done is a shared checklist that establishes when a user story or product increment is considered complete.

A user story can be marked as Done only when all applicable criteria are satisfied.

### Definition of Done Checklist

- [ ] All agreed acceptance criteria are satisfied.
- [ ] Code is implemented according to project coding standards.
- [ ] Code review is completed and approved.
- [ ] Unit and integration tests are executed successfully.
- [ ] No critical or high-severity defects remain unresolved.
- [ ] Security and data validation checks are completed.
- [ ] Relevant documentation is updated.
- [ ] Changes are successfully integrated into the main development branch.
- [ ] The feature is verified in the testing environment.
- [ ] Product Owner acceptance is obtained where required by the team's agreed process.

## 3. Scrum Roles

| Scrum Accountability | Responsibilities |
|---|---|
| Product Owner | Defines and orders the Product Backlog, communicates the product vision, and maximises product value. |
| Scrum Master | Establishes Scrum practices, coaches the team, and helps remove impediments. |
| Developers | Build and test the product increment and collectively maintain quality. |

## 4. Scrum Events

| Scrum Event | Purpose |
|---|---|
| Sprint | A fixed-length period in which the team creates a usable product increment. |
| Sprint Planning | Defines the Sprint Goal and selects work for the Sprint. |
| Daily Scrum | A daily event for Developers to inspect progress towards the Sprint Goal and adapt their plan. |
| Sprint Review | Inspects the Sprint outcome with stakeholders and discusses future adaptations. |
| Sprint Retrospective | Identifies improvements to team effectiveness and quality. |

## 5. Scrum Artifacts

| Artifact | Description | Commitment |
|---|---|---|
| Product Backlog | Ordered list of work needed to improve the product. | Product Goal |
| Sprint Backlog | Sprint Goal, selected Product Backlog items, and the plan for delivering them. | Sprint Goal |
| Increment | A usable, integrated step towards the Product Goal. | Definition of Done |
