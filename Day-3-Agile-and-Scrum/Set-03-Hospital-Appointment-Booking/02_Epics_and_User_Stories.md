# Task 2 – Epics and User Stories

## 1. Introduction

The Hospital Appointment Booking Application is divided into four major epics. Each epic represents a group of related functionalities required to manage patient appointments and doctor schedules.

## 2. Epic 1 – Appointment Booking

**Epic Description:** Enables patients to search for doctors, view available appointment slots, and book appointments.

| Story ID | User Story | Description |
|---|---|---|
| US-01 | Search for Doctors | As a patient, I want to search for doctors by name or speciality so that I can find the appropriate doctor. |
| US-02 | View Available Appointment Slots | As a patient, I want to view available appointment slots so that I can choose a convenient time. |
| US-03 | Book an Appointment | As a patient, I want to book an available appointment slot so that I can schedule a consultation with a doctor. |

## 3. Epic 2 – Appointment Rescheduling and Cancellation

**Epic Description:** Allows patients to modify or cancel existing appointments.

| Story ID | User Story | Description |
|---|---|---|
| US-04 | View Existing Appointments | As a patient, I want to view my upcoming appointments so that I can manage my bookings. |
| US-05 | Reschedule an Appointment | As a patient, I want to select a new available time slot for an existing appointment so that I can change my consultation time. |
| US-06 | Cancel an Appointment | As a patient, I want to cancel an upcoming appointment so that the appointment slot can become available to others. |

## 4. Epic 3 – Appointment Reminders

**Epic Description:** Provides timely notifications to patients about their upcoming appointments and changes.

| Story ID | User Story | Description |
|---|---|---|
| US-07 | Receive Booking Confirmation | As a patient, I want to receive a confirmation notification after booking an appointment so that I know my booking was successful. |
| US-08 | Receive Appointment Reminders | As a patient, I want to receive reminders before my appointment so that I do not forget my consultation. |
| US-09 | Receive Appointment Change Notifications | As a patient, I want to receive notifications when my appointment is rescheduled or cancelled so that I stay informed about changes. |

## 5. Epic 4 – Doctor Schedule Management

**Epic Description:** Allows doctors and authorised hospital staff to manage doctor availability and appointment schedules.

| Story ID | User Story | Description |
|---|---|---|
| US-10 | Set Doctor Availability | As a doctor, I want to set my available consultation days and hours so that patients can book appointments during suitable times. |
| US-11 | Update Doctor Availability | As a doctor, I want to update my availability so that patients can see the latest appointment slots. |
| US-12 | View Doctor Appointment Schedule | As a doctor, I want to view my daily appointment schedule so that I can prepare for upcoming consultations. |

## 6. Epic and Story Summary

|---|---|---:|

## 7. Conclusion

The four epics organise the application's major functionalities into manageable groups. The 12 user stories describe the requirements from the perspective of patients and doctors.
