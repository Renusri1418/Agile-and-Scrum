# Task 2 – Epics and User Stories

## Project: Insurance Claims Portal

The product backlog is divided into four major epics. Each epic represents a key functional area of the Insurance Claims Portal.

## Epic 1: Claim Registration (EP-01)

**Description:** Enables policyholders to register new insurance claims by providing policy and incident information.

| Story ID | User Story |
|---|---|
| US-01 | As a policyholder, I want to log in securely so that I can access my insurance account. |
| US-02 | As a policyholder, I want to select my insurance policy so that I can register a claim under the correct policy. |
| US-03 | As a policyholder, I want to enter incident details so that the insurance company understands what happened. |
| US-04 | As a policyholder, I want to submit my claim so that the insurance company can begin processing it. |

## Epic 2: Document Upload (EP-02)

**Description:** Allows policyholders to submit the supporting documents required for claim verification.

| Story ID | User Story |
|---|---|
| US-05 | As a policyholder, I want to upload identity documents so that my identity can be verified. |
| US-06 | As a policyholder, I want to upload photographs of the incident so that I can provide supporting evidence. |
| US-07 | As a policyholder, I want to upload bills and receipts so that the claim amount can be verified. |
| US-08 | As a policyholder, I want to view uploaded documents so that I can confirm that the correct files were submitted. |

## Epic 3: Claim Tracking (EP-03)

**Description:** Provides visibility into the progress and current status of submitted insurance claims.

| Story ID | User Story |
|---|---|
| US-09 | As a policyholder, I want to view my submitted claims so that I can access their details. |
| US-10 | As a policyholder, I want to view the current status of a claim so that I know its processing stage. |
| US-11 | As a policyholder, I want to view requests for additional information so that I can provide missing details. |

## Epic 4: Settlement Notifications (EP-04)

**Description:** Keeps policyholders informed about claim decisions and settlement updates.

| Story ID | User Story |
|---|---|
| US-12 | As a policyholder, I want to receive notifications when my claim status changes so that I remain informed. |
| US-13 | As a policyholder, I want to receive a notification when my claim is approved or rejected so that I know the decision. |
| US-14 | As a policyholder, I want to view settlement details so that I understand the approved payment amount and settlement status. |

## Backlog Summary

| Epic | Number of Stories |
|---|---:|
| Claim Registration | 4 |
| Document Upload | 4 |
| Claim Tracking | 3 |
| Settlement Notifications | 3 |
| **Total** | **14** |

## Conclusion

The 14 user stories cover the four major functional areas of the Insurance Claims Portal. They describe the system from the policyholder's perspective and provide a foundation for backlog refinement, INVEST evaluation, acceptance criteria, and estimation.
