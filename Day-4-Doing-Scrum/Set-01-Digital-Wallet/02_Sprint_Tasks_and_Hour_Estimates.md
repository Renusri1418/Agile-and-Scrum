# Task 2 – Sprint Tasks and Hour Estimates

## 1. Introduction

The selected user stories are divided into smaller development tasks. Each task is assigned an estimated number of working hours to help the team plan and track its work.

The three selected stories are:

- US-01: Register and log in to the wallet.
- US-03: Add money to the wallet.
- US-04: View transaction history.

## 2. Story US-01 – Register and Log In

**Story Points: 5**

| Development Task | Estimated Hours |
|---|---:|
| Design registration and login screens | 3 |
| Develop user registration functionality | 5 |
| Implement login and authentication | 6 |
| Validate user input and error messages | 3 |
| Perform unit and integration testing | 3 |
| **Total** | **20 hours** |

## 3. Story US-03 – Add Money to Wallet

**Story Points: 5**

| Development Task | Estimated Hours |
|---|---:|
| Design the add-money interface | 2 |
| Develop the add-money functionality | 5 |
| Integrate the payment gateway | 6 |
| Update the wallet balance | 3 |
| Perform payment and transaction testing | 4 |
| **Total** | **20 hours** |

## 4. Story US-04 – View Transaction History

**Story Points: 3**

| Development Task | Estimated Hours |
|---|---:|
| Design the transaction history screen | 2 |
| Develop transaction history retrieval | 4 |

| **Total** | **12 hours** |

## 5. Summary

| User Story | Story Points | Estimated Hours |
|---|---:|---:|
| US-01 – Register and Log In | 5 | 20 |

Breaking user stories into smaller tasks makes the work easier to understand, assign and track. Hour estimates help the team plan its daily activities and identify possible delays.
